# Yash Chavan — Portfolio

Responsive personal portfolio built with React, Vite, CSS and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Before publishing
- Replace placeholder GitHub and LinkedIn profile URLs in `src/App.jsx` with your actual profiles.
- Add your resume as `public/resume.pdf`.
- Add verified repository/demo links and screenshots when ready.
- Review project descriptions and skill lists for accuracy.

The project section contains only the three projects from your resume: GeoHealth AI, ExamSmart and Hospital Management System.

## Build

```bash
npm run lint
npm run build
```

## Deploy
Push to GitHub, import the repository into Vercel, then add `theyashchavan.me` in Project Settings → Domains. Copy the exact DNS records Vercel provides into Namecheap. Vercel provisions HTTPS after DNS verification.
